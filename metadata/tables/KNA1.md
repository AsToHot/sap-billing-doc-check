# KNA1 — 客户主数据（Customer Master General）
> ✅ 字段定义从 SAP DD03L 实时读取验证（2026-05-29）

## 基础信息
- **表名**: KNA1（SD 模块）
- **用途**: 客户主数据基本视图（名称、地址、税号等）
- **主键**: MANDT + KUNNR

## 核心字段（按位置排序）

| 位置 | 字段 | 类型/长度 | 主键 | 说明 |
|:----:|------|:---------:|:----:|------|
| 0001 | MANDT | CLNT(3) | X | 集团 |
| 0002 | KUNNR | CHAR(10) | X | **客户号** |
| 0003 | LAND1 | CHAR(3) | | **国家/地区代码** |
| 0004 | NAME1 | CHAR(35) | | **名称1**（公司名） |
| 0005 | NAME2 | CHAR(35) | | **名称2** |
| 0006 | ORT01 | CHAR(35) | | **城市** |
| 0008 | REGIO | CHAR(3) | | **地区/省份** |
| 0009 | SORTL | CHAR(10) | | 排序字段 |
| 0010 | STRAS | CHAR(35) | | **街道/地址** |
| 0037 | KTOKD | CHAR(4) | | 客户账户组 |
| 0042 | LOEVM | CHAR(1) | | **删除标记**（空=正常, X=已删除） |
| 0052 | SPERR | CHAR(1) | | **冻结标记** |
| 0054 | STCD1 | CHAR(16) | | **税号1** |
| 0055 | STCD2 | CHAR(11) | | **增值税号** |

## 关联表
- **KNB1** → 公司代码层数据（含统驭科目等）
- **KNVV** → 销售组织层数据（含定价、开票等）
- **KNVP** → 客户合作伙伴功能

## 在开票查询中的用途
- `fetch-delivery-data.js` 查询客户名称用于展示
- 对账时显示客户全称而非仅客户编号
- 注意事项：KNA1 不含销售组织维度的开票数据（需查 KNVV）
