# LIPS — 交货单行项目（Delivery Item Data）
> ✅ 字段定义从 SAP DD03L 实时读取验证（2026-05-29）

## 基础信息
- **表名**: LIPS（SD 模块）
- **用途**: 存储交货单的行项目数据
- **关联**: N:1 ← LIKP（抬头），通过 VBELN

## 核心字段（按位置排序）

| 位置 | 字段 | 类型/长度 | 主键 | 说明 |
|:----:|------|:---------:|:----:|------|
| 0001 | MANDT | CLNT(3) | X | 集团 |
| 0002 | VBELN | CHAR(10) | X | **交货单号** |
| 0003 | POSNR | NUMC(6) | X | **行项目号**（000010, 000020） |
| 0004 | PSTYV | CHAR(4) | | 行项目类别 |
| 0008 | MATNR | CHAR(40) | | **物料号**（注意：标准 SAP 长度 40） |
| 0011 | WERKS | CHAR(4) | | **工厂** |

## FKSTA 行项目开票状态

| 值 | 含义 |
|:--:|------|
| 空 | ❌ 未开票 |
| A | ⚠️ 部分开票 |
| C | ✅ 已全额开票 |

> **注意**：FKSTA 在位置 0318，是 LIPS 表中较靠后的字段。开票脚本中检查 FKSTA 来判断该行是否已开票。

## 关键查询
```sql
SELECT VBELN, POSNR, MATNR, ARKTX, LFIMG, VRKME, FKIMG, FKSTA, VGBEL, VGPOS
FROM LIPS
WHERE VBELN IN ('8000001354', '8000001355');
```

## 注意事项
- **MATNR 长度 40**（不是旧系统的 18）
- **FKIMG**（开票数量）字段不在此表的标准 DD03L 中，可能存在于后续位置或由开票状态派生
- **ADT 不支持 JOIN**：LIKP/LIPS/VBRP 分步查询后本地拼接
